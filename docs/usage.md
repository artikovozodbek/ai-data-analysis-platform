# Usage Guide

## Upload a Dataset

1. Navigate to `http://127.0.0.1:8000/ui/upload.html`
2. Select a dataset in CSV, Excel, JSON, TXT, TSV, or Parquet format.
3. Submit the upload form.

## Preview the Dataset

1. Use the dataset id returned by the upload endpoint.
2. Navigate to `http://127.0.0.1:8000/ui/preview.html` and follow the instructions.

## Run AI Chat

1. Navigate to `http://127.0.0.1:8000/ui/chat.html`.
2. Enter a dataset id and a natural language question.
3. Ask about missing values, correlations, or dataset summaries.

## Generate Reports

1. Navigate to `http://127.0.0.1:8000/ui/reports.html`.
2. Enter the dataset id to generate an HTML report.
